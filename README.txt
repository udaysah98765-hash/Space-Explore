# 3D Space Explorer — Premium

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet is required on first load because Three.js is loaded from jsDelivr CDN.

## Controls
- Drag mouse / finger = 360° rotate
- Scroll / pinch = zoom
- Explore Now = jump to planets
- Random Tour = random planet
- Fullscreen = fullscreen mode

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a GitHub repository.
Then enable GitHub Pages from Settings → Pages → Deploy from branch.
